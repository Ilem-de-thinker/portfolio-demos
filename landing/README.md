# The Five Ateliers — Selector Landing Page

A bespoke standalone landing project showcasing 5 award-winning personal portfolio architectures with live previews and WhatsApp conversion drawer.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production deployment
npm run build
```

## How to Configure

All showcase designs, WhatsApp dispatch phone number, FAQs, and studio copy can be edited in:
`src/config.js`

- **WHATSAPP_NUMBER**: Update to your international phone number (e.g. `14155552671`, no `+` or hyphens).
- **DESIGNS**: Add or customize portfolio designs, tags, and swatches.
