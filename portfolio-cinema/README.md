# Mateo Thorne — Cinema Portfolio

A widescreen 2.39:1 anamorphic film director portfolio. Features letterbox opening sequence, pinned scroll parallax title scaling and dissolve, horizontal work reel with chapter markers, and film still inspection modals.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run dev server
npm run dev

# 3. Build static production site
npm run build
```

## How to Edit Content

Edit a single file: `src/content.js`.
You can update films, festival laurels, synopses, and production contact information directly.
