# Elena Radek — Swiss Brutal Systems Portfolio

A rigid 12-column Swiss International Style product design and systems architecture portfolio. Features real-time velocity-scrubbed opposing marquees, sticky stacked architectural project panels, live Zurich CET atomic telemetry, and signal orange energy.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run dev server
npm run dev

# 3. Build static production site
npm run build
```

## How to Edit Content

Edit a single file: `src/content.js`.
You can modify Elena Radek's projects, design tokens, stats, timeline, and audit dispatch settings easily.
