# Camille Laurent — Atelier Portfolio

An organic, calm ceramicist and botanical illustrator portfolio. Features slow hypnotic SVG blob morphing, masked rising typography, asymmetric parallax pairs, expanding rounded mask reveals, and collector reflections.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run dev server
npm run dev

# 3. Build static production site
npm run build
```

## How to Edit Content

Edit a single file: `src/content.js`.
You can update vessels, clays, kiln notes, exhibitions, and collector letters easily.
