# Dr. Kaelen Vance — Signal Technical Portfolio

A futuristic, high-performance systems engineering portfolio. Features interactive real-time particle/wave canvas field, matrix-grade character scramble decode, 3D perspective card tilt with cyan light-sweep edge highlights, and scroll-scrubbed motherboard circuit trace lines.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run dev server
npm run dev

# 3. Build static production site
npm run build
```

## How to Edit Content

Edit a single file: `src/content.js`.
You can update systems, benchmarks, protocols, academic publications, and terminal dispatch parameters effortlessly.
