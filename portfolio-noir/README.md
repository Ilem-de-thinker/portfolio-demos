# Julian Vance — Noir Editorial Portfolio

A haute-couture fashion & monochrome photography portfolio inspired by Paris monograph aesthetics, featuring reactive 20vw+ typography, spotlight portrait mask, scrubbed word-by-word manifesto, and floating contact sheet preview index.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run dev server
npm run dev

# 3. Build static production site
npm run build
```

## How to Edit Content

Edit a single file: `src/content.js`.
You can change Julian Vance's name, bio, exhibition dates, projects, photographs, and contact information without touching any React code.
